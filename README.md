# ⚽ Premier League: Financial Efficiency & Performance Analytics (2012–2025)

An interactive, bilingual (English/Spanish) sports analytics dashboard exploring the relationship between transfer market spending and league points return across Premier League clubs.

🔗 **Live Interactive App:** https://premier-league-analytics-xdbfznpahjw2vahhagvavp.streamlit.app/
---

## 📊 Overview & Analytical Focus
- **Core Hypothesis:** Does outspending rivals guarantee sporting success in elite football?
- **Methodology:** Linear regression benchmarking to calculate *expected league points* based on net transfer investment, deriving club efficiency residuals.
- **Key Visualizations:**
  - Dynamic KPI summaries (Total spend, average points return, cost per point).
  - Spending vs. Performance quadrant analysis with league-wide historical averages.
  - Net sporting efficiency ranking by club.

---

## 🛠️ Tech Stack & Architecture
- **Language:** Python
- **Data Manipulation:** Pandas
- **Visualization:** Plotly Graph Objects & Express
- **Application Framework:** Streamlit
- **UI/UX Design:** Custom CSS (Premier League Dark Broadcast Aesthetic)
